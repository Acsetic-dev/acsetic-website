ACSETIC WEBSITE STARTER

Files:
- index.html: website page structure
- style.css: colours and layout
- script.js: demo search, cart and seller submission behaviour

How to use:
1. Keep all three files together in one folder.
2. Open index.html in a browser to view the prototype.

Important:
This is a front-end demonstration only. Seller submissions are stored in the browser's local storage, not Supabase. The admin review section is not a secure admin system. There are no real user accounts, orders, delivery or payments. Before public launch, we must connect Supabase, complete security policies, and implement secure admin approval and server-side checkout.
